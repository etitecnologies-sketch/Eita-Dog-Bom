## 🚀 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/etitecnologies-sketch/Eita-Dog-Bom.git
   ```

2. Abra o arquivo `eita-dog-bom.html` no navegador — **nenhuma dependência necessária**, funciona 100% offline.

3. Para publicar online, basta fazer o upload do arquivo HTML em qualquer serviço de hospedagem:
   - **GitHub Pages** (gratuito)
   - **Netlify** (gratuito)
   - **Vercel** (gratuito)
